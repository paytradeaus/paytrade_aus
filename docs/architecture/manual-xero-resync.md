# Manual Xero Re-sync by ID (Task #65)

Self-service recovery tool (any company user — STANDARD_USER, ADMIN, PRIMARY_ADMIN — gated by an in-resolver IDOR check that rejects company_id tampering against the JWT). Triggered from a "Manual sync" button next to Refresh in the Sync Log header on the Xero dashboard, opens a `BaseModal` dialog (`ManualXeroSyncDialog`) where the user picks a record type, pastes the Xero ID (or invoice/bill number for invoice_bill), clicks Run sync. Result panel renders inline below the form so the user can run several IDs without closing the dialog. Re-pulls a single Xero record and re-runs the existing inbound webhook handler stamped with `sync_run_type: 'manual'`. New service method `XeroWebhookService.manualXeroResync(decoded, { company_id, type, id })` (~L13262 in `webhook.service.ts`) handles five record types: `invoice_bill` (resolves invoice number → GUID via `getInvoices` with `where: 'InvoiceNumber=="..."'` when input isn't a UUID, then calls `handleInvoiceCreateUpdate`), `payment` (resolves Xero payment → invoice id → `handleInvoiceCreateUpdate`), `bank_transfer` (parses `PT-RET-{id}` reference → linked PT payment → claim invoice → `handleInvoiceCreateUpdate`), `contact` (`handleContactCreateUpdate`), `manual_journal` (`handleManualJournalUpdate`, anti-echo aware via `xeroManualJournalService.findByManualJournalId`). Always writes a template-499 trigger log (`MANUAL_XERO_SYNC_TRIGGERED`) regardless of outcome. Reuses the existing `XeroService.refreshTokenSet` Redis-locked token refresh and the existing `xero` `XeroClient` from the constructor. **Resolver**: `manualXeroResync(company_id, type, id)` mutation in `xero.resolver.ts` gated by `@UseGuards(JwtAuthGuard, RolesGuard) @Roles(Role.ADMIN, Role.PRIMARY_ADMIN)`; non-admin standard users get a guard rejection. Returns standard `StringResponse` with JSON-stringified `{ success, message, syncLogId, resolvedXeroId }` payload, plus the standard `XERO_REFRESH` flow when the refresh token is dead. **Frontend**: `manualXeroResync` helper in `integration.functions.ts` parses the JSON payload and toasts result. New `ManualXeroSyncCard` component appended to `XeroDashboard/index.tsx` (under the cards grid, before Sync Log) — type dropdown + ID input + Run sync button + inline result panel with sync log link. Out of scope (deferred): bulk paste, fuzzy search, bulk re-pull, reverse direction (PT → Xero push), cross-company.
