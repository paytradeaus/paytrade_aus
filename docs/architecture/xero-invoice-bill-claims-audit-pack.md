# Xero Invoice/Bill on Claims + Audit Pack

`xero_invoices_bills` carries cached_pdf_object_key, last_fetched_at, deep_link_url, current_xero_status, is_stale, void_date. PDFs are pulled via `getInvoiceAsPdf` and stored on R2 under `xero_pdfs/<invoiceId>.pdf`. The webhook handler (INVOICE.UPDATE/CREATE) refreshes the cache; DELETE/VOID flips `is_stale=true` while preserving the cached PDF for audit. The 15-min webhook fallback scheduler reuses the same handler so cache refresh is automatic. `XeroSchedulerService.onApplicationBootstrap()` runs a throttled (~55/min) backfill so legacy rows get a cached PDF. Frontend `XeroIntegration` expander in `AddUpdateClaims.tsx` shows invoice number, status, deep link and a Download Xero PDF button — the latter calls GraphQL `getXeroInvoicePdfDownloadToken` (5-min JWT) and then GET `/files/xeroPdf` with `Authorization: Bearer <token>`. Audit-pack ZIPs include the cached PDF in `<module>/Attachments/Xero-<reference|invoiceId>.pdf` and the per-claim Excel adds Xero Invoice #, Xero Status, Xero Link columns.
