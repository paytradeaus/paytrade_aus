PayTrade Admin Guide: Recurring Tasks

Essential maintenance tasks that keep PayTrade running smoothly. Some are automated, others require periodic manual action.

Manual Admin Tasks

📅 Update Public Holidays MANUAL

Ad-hoc — required before current dates run out

The holiday table drives all business day calculations for payment claim due dates and QBCC notice deadlines. If the table runs out of future dates, these calculations will be incorrect.

Why it matters: Payment claims use business days (excluding weekends and public holidays) to calculate statutory deadlines. Missing holidays mean incorrect due dates, which can create compliance issues for your users.

How to do it:

  1. Go to Admin → Holidays
  2. Check the latest date in the list — if it's within the next 3 months, add more
  3. Add each state/territory public holiday for the upcoming year(s)
  4. For recurring holidays (e.g., Christmas, New Year), tick "Recurring every year" — these get auto-copied each December
  5. For one-off holidays (e.g., Queen's Birthday varies), add them manually each year
  6. You can also bulk import holidays from an Excel file using the Import button

Dashboard alert: A warning banner appears on the admin dashboard when holiday coverage drops below 90 days. An email alert is also sent monthly if action is needed.

📋 Submit & Confirm QBCC Notices MANUAL

As they arise — check dashboard daily

When users perform certain actions (opening a trust account, making payments, closing accounts), the system automatically generates QBCC notices. These notices need admin review and confirmation before being sent to the QBCC.

Why it matters: QBCC notices are a legal compliance requirement under the BIF Act. Delays in sending notices can put users at risk of non-compliance.

How to do it:

  1. Check the NOTICES panel on your Dashboard — this shows unsent notices
  2. Click into each notice to review the generated PDF document
  3. Verify the details are correct (account names, dates, amounts)
  4. Click "Save & Send" to mark as sent and dispatch to QBCC
  5. You can also go to Admin → Notices for the full list

✅ Monitor Compliance Issues MANUAL

Daily check recommended

The system tracks compliance status for all projects with trust accounts. When issues are detected (missing notices, overdue actions), they appear on your dashboard.

How to do it:

  1. Check the COMPLIANCE panel on your Dashboard
  2. Review each flagged project to understand the compliance gap
  3. Contact the user if they need to take action, or resolve from admin side
  4. Full list at Admin → Compliances

💳 Review Failed Subscriptions MANUAL

Weekly check recommended

When subscription payments fail (expired cards, insufficient funds), these appear on the dashboard. Admins should follow up with affected businesses.

How to do it:

  1. Check the SUBSCRIPTIONS panel on your Dashboard
  2. Click on a failed subscription to contact the business's primary admin
  3. Full history at Admin → Subscriptions → Billing History

🏦 Resolve Trust Accounting Issues MANUAL

As they arise

When journal entries have balance errors or bank accounts show discrepancies, they are flagged on the dashboard. These require investigation and resolution.

How to do it:

  1. Check the TRUST ACCOUNTING ISSUES panel on your Dashboard
  2. Review the flagged accounts for journal or balance check errors
  3. Contact the business admin to resolve discrepancies
  4. Full list at Admin → Journals

👥 Review New User Registrations MANUAL

Daily check recommended

New users and businesses that sign up appear on your dashboard. Review them to ensure they are legitimate and their setup is progressing correctly.

How to do it:

  1. Check NEW USERS and NEW BUSINESSES panels on your Dashboard
  2. Click into each to review their details and status
  3. Full lists at Admin → Users and Admin → Businesses

📝 Manage SEO Keywords & Content MANUAL

Periodically — as needed for marketing

SEO keyword landing pages drive organic traffic. Periodically review and update keywords, page content, and meta descriptions to maintain search rankings.

How to do it:

  1. Go to Admin → SEO Keywords
  2. Review keyword statuses — publish new ones, update existing content
  3. Use Export JSON to back up all keywords before major changes
  4. Use Import JSON to bulk update or restore keywords

Automated Tasks (No Action Needed)

These processes run automatically. They're listed here for awareness so you know what the system handles on its own.

🔄 Recurring Holiday Mapping AUTOMATIC

December 31st each year at 11:50 PM UTC

The system automatically copies holidays marked as "Recurring every year" to the next calendar year. Non-recurring holidays (like Easter, which changes date) are not copied — a reminder email is sent on December 15th to prompt manual addition.

📧 Holiday Expiry Email Alerts AUTOMATIC

1st of every month at 8:00 AM UTC

If the holiday table has fewer than 90 days of coverage remaining, an email alert is sent to the admin. This ensures you have advance warning before the table runs out.

📩 Pending QBCC Notice Reminders AUTOMATIC

Daily at midnight UTC

The system sends reminder emails for QBCC notices that remain in "Pending" status, ensuring no notice is forgotten. This runs as a nightly batch.

🛡️ Project Compliance Checks AUTOMATIC

Daily at 8:00 AM UTC

All project compliance statuses are recalculated each morning. Any new issues are flagged and appear on the admin dashboard.

💾 Database Backups AUTOMATIC

Weekly (production only)

A full PostgreSQL database backup (pg_dump) is created weekly, uploaded to Object Storage, and old backups beyond 7 iterations are cleaned up. No action required.

🔗 Xero Integration Sync AUTOMATIC

Daily at 1:00 PM UTC

For businesses with active Xero integrations, the system refreshes OAuth tokens and syncs data (Accounts, Contacts, Projects, Contracts, Invoices). It also deactivates integrations for expired subscriptions.

Admin action only if: A user reports their Xero sync has stopped working — they may need to re-authenticate their Xero connection.

🤖 Community Bot Content AUTOMATIC

Scheduled via cron

The community bot uses AI (GPT-4o) to generate realistic Q&A content for the community section. It creates bot users with realistic personas and posts relevant questions and answers about construction trust accounting.

❤️ Health Monitoring & Auto-Restart AUTOMATIC

Continuous (production only)

The production server monitors the backend's /health endpoint. If the backend becomes unresponsive, it automatically restarts it and sends an email alert via Brevo. The KeepAliveModule ensures the server stays warm.
