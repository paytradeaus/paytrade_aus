<h1 style=""color: #333;"">Xero Account Mapping and Settings</h1>
<p style=""font-size: 18px; color: #555;"">Configure your chart of accounts, tax rates, tracking categories, and sync preferences before syncing data between PayTrade and Xero.</p>
<div style=""margin: 16px 0; padding: 16px; background: #fff3e0; border-radius: 8px; border-left: 4px solid #ff9800;""><strong>Important:</strong> Complete these settings <strong>before</strong> attempting to sync invoices or bills. Missing account codes or tax rates will cause sync errors.</div>
<h2 style=""color: #1a73e8; border-bottom: 2px solid #1a73e8; padding-bottom: 8px; margin-top: 32px;"">Getting to Xero Settings</h2>
<div style=""display: flex; gap: 16px; margin: 16px 0; padding: 16px; background: #f8f9fa; border-radius: 8px; border-left: 4px solid #1a73e8;""><div style=""min-width: 36px; height: 36px; background: #1a73e8; color: white; border-radius: 50%; display: flex; align-items: center; justify-content: center; font-weight: bold; font-size: 16px;"">1</div><div><strong style=""font-size: 16px;"">Open the Xero Dashboard</strong><p style=""margin: 4px 0 0; color: #555;"">Navigate to <strong>Integrations</strong> in the sidebar, then click on your Xero connection to open the Xero Dashboard.</p></div></div>
<div style=""display: flex; gap: 16px; margin: 16px 0; padding: 16px; background: #f8f9fa; border-radius: 8px; border-left: 4px solid #1a73e8;""><div style=""min-width: 36px; height: 36px; background: #1a73e8; color: white; border-radius: 50%; display: flex; align-items: center; justify-content: center; font-weight: bold; font-size: 16px;"">2</div><div><strong style=""font-size: 16px;"">Click Settings</strong><p style=""margin: 4px 0 0; color: #555;"">Click <strong>""Settings""</strong> on the Xero Dashboard or navigate directly to <strong>Xero Settings</strong>.</p></div></div>

<h2 style=""color: #1a73e8; border-bottom: 2px solid #1a73e8; padding-bottom: 8px; margin-top: 32px;"">Tax Rate Configuration</h2>
<div style=""display: flex; gap: 16px; margin: 16px 0; padding: 16px; background: #f8f9fa; border-radius: 8px; border-left: 4px solid #1a73e8;""><div style=""min-width: 36px; height: 36px; background: #1a73e8; color: white; border-radius: 50%; display: flex; align-items: center; justify-content: center; font-weight: bold; font-size: 16px;"">1</div><div><strong style=""font-size: 16px;"">Set Invoice Tax Code</strong><p style=""margin: 4px 0 0; color: #555;"">Choose the default tax rate for invoices synced to Xero (e.g., GST on Income 10%).</p></div></div>
<div style=""display: flex; gap: 16px; margin: 16px 0; padding: 16px; background: #f8f9fa; border-radius: 8px; border-left: 4px solid #1a73e8;""><div style=""min-width: 36px; height: 36px; background: #1a73e8; color: white; border-radius: 50%; display: flex; align-items: center; justify-content: center; font-weight: bold; font-size: 16px;"">2</div><div><strong style=""font-size: 16px;"">Set Bill Tax Code</strong><p style=""margin: 4px 0 0; color: #555;"">Choose the default tax rate for bills synced to Xero (e.g., GST on Expenses 10%).</p></div></div>
<p>You can also create new tax rates with custom components, compound tax support, and specific report tax types (Input, Output, None, Exempt).</p>
<h2 style=""color: #1a73e8; border-bottom: 2px solid #1a73e8; padding-bottom: 8px; margin-top: 32px;"">Tracking Categories</h2>
<p>Tracking categories in Xero are used to categorise transactions by project and contract. PayTrade uses two:</p>
<div style=""display: flex; gap: 16px; margin: 16px 0; padding: 16px; background: #f8f9fa; border-radius: 8px; border-left: 4px solid #1a73e8;""><div style=""min-width: 36px; height: 36px; background: #1a73e8; color: white; border-radius: 50%; display: flex; align-items: center; justify-content: center; font-weight: bold; font-size: 16px;"">1</div><div><strong style=""font-size: 16px;"">Project Tracking Category</strong><p style=""margin: 4px 0 0; color: #555;"">Select the Xero tracking category that represents PayTrade projects. Each PayTrade project will map to an option within this category.</p></div></div>
<div style=""display: flex; gap: 16px; margin: 16px 0; padding: 16px; background: #f8f9fa; border-radius: 8px; border-left: 4px solid #1a73e8;""><div style=""min-width: 36px; height: 36px; background: #1a73e8; color: white; border-radius: 50%; display: flex; align-items: center; justify-content: center; font-weight: bold; font-size: 16px;"">2</div><div><strong style=""font-size: 16px;"">Contract Tracking Category (Optional)</strong><p style=""margin: 4px 0 0; color: #555;"">Select the Xero tracking category that represents PayTrade contracts. Each contract will map to an option within this category.</p></div></div>
  <div style=""margin: 16px 0; padding: 16px; background: #e3f2fd; border-radius: 8px; border-left: 4px solid #1a73e8;""><strong>Note:</strong> Contract mapping is <strong>optional</strong>. PayTrade can automatically determine the correct contract in most cases. You only need to map contracts if a subcontractor has <strong>multiple contracts under the same project</strong> and the claim amount does not uniquely match one of them. For most users, project mapping alone is sufficient.</div>
<div style=""margin: 16px 0; padding: 16px; background: #fff3e0; border-radius: 8px; border-left: 4px solid #ff9800;""><strong>Important:</strong> You cannot use the same tracking category for both projects and contracts. They must be different categories.</div>
<div style=""margin: 16px 0; padding: 16px; background: #e8f5e9; border-radius: 8px; border-left: 4px solid #4caf50;""><strong>Tip:</strong> If the tracking category doesn't exist yet, you can create it directly from Settings.</div>

<h2 style=""color: #1a73e8; border-bottom: 2px solid #1a73e8; padding-bottom: 8px; margin-top: 32px;"">Other Settings</h2>
<ul>
        <li><strong>Reference Format:</strong> Customise the reference prefix for synced documents (e.g., ""PT-INV-"" for invoices).</li>
        <li><strong>Processing Wait Time:</strong> Set a delay (0–60 minutes) before processing payment notifications from Xero. This allows PayTrade to wait for all related records (e.g., a part payment followed by a credit note) to arrive before determining the correct payment type. A setting of 5–15 minutes is recommended for most construction companies. See the <strong>""Xero Payment Synchronisation""</strong> guide for more detail.</li>
      </ul>
<div style=""margin: 16px 0; padding: 16px; background: #e3f2fd; border-radius: 8px; border-left: 4px solid #1a73e8;""><strong>Note:</strong> Once all settings are configured, proceed to <strong>""Mapping Bank Accounts, Contacts, Projects and Contracts in Xero""</strong> to complete the onboarding wizard.</div>"
