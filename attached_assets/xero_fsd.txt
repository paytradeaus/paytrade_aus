Overview
Pay Trade allows integration with Xero application to sync the invoices and bills from Xero to Pay Trade and vice
versa.This integration makes the process easier upon the user who wants to use Xero for payments and Pay Trade for
the trust accounting purposes. We generate journals and audit related documents from the data receiving during this
sync.

B. Paytrade > xero syncing
1. The field ‘Sync invoice as draft?’ has a data ‘Yes/No’ if selected as ‘Yes’ the invoice from xero will save as draft in
the paytrade.
2. Sync bill as draft? Field will also has a data ‘Yes/No’ If ‘Yes’ the Approved bill will also save as ‘Draft’ in the Claim
screen.
3. Sync payments as draft?* field has a default data as ‘No’.
C. Xero syncing > Paytrade
1. The field ‘Sync invoice as draft?’ has a data ‘Yes/No’ if selected as ‘Yes’ the invoice from paytrade will save as
draft in the Xero.
2. Sync bill as draft? Field will also has a data ‘Yes/No’ If ‘Yes’ the Approved bill will also save as ‘Draft’ in the Claim
screen.
3. Sync payments as draft?* field has a ‘Yes/No’. If yes the payment under Xero will save as ‘draft’ else ‘No’ will save
as Completed state.
4. Xero > Pay Trade system works on the basis of Receive Web Hook or scheduled check or unscheduled check
prompted by transaction activity.
D. Xero account code
1. The section contains the list of field with the dropdown data ‘In PayTrade, each field in the dropdown is mapped to
the corresponding field in Xero, and the sync process takes place based on the selected data.”
2. When creating invoice and bills there are specific accounts that line items are mapped to. These accounts need to
be input into the setting areas by the user which when Pushing data we push with these account fields, and when
we get data, we validate against them to create a successful import.
